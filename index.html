About

I'm a gameplay and systems programmer in Tel Aviv. I work on games that run where there is no room to be wasteful.

At Communix I build and operate Chip Master, a live real-stakes multiplayer poker game shipped to Unity WebGL. Browser WASM is the tightest commercial runtime in games: a fixed heap the browser enforces, no swap, no platform SDK, and a download size that decides whether a player ever sees the first frame. Holding a framerate inside those limits is the same discipline as shipping to a console, and it is most of what I do. Because the stakes are real, the game is server-authoritative throughout — a divergence between client and server is a correctness bug with money attached, not a visual glitch.

I also build our AI-assisted development tooling: a multi-agent pipeline that generates Unity scenes, assets and gameplay scaffolding, shortening the distance between an idea and something playable.

Before games I spent three years at Check Point writing production C and C++ for high-throughput gateway systems, in a multi-million-line codebase where a fault takes down customer traffic. That is where I learned to profile, to reason about memory, and to debug what only fails under load. I hold a BSc in Computer Science from Bar Ilan University.

I'm looking to work on large-scale games abroad and I'm open to relocation. Outside work I'm drawn to exploring different cultures, and to tabletop RPGs, where most of my design thinking comes from.

Projects

Chip Master

Live Unity WebGL / WASM Multiplayer Server-Authoritative Performance

Shipped and in live operation at Communix. A real-stakes multiplayer poker game built in Unity and delivered to WebGL, running in mobile Safari and Chrome rather than as a native app. The constraint is the work: a browser-enforced WASM heap with no swap, no platform SDK to fall back on, and a download size that determines whether a player reaches the first frame at all. The engineering is memory budgeting, load-time and build-size reduction, and frame-time profiling against a hard ceiling — the same discipline as a fixed-hardware console target. Because money is at stake, game state is server-authoritative end to end, with reconciliation and reconnect handling built for correctness rather than appearance.

Warriors : Rise to Glory

A turn-based dice combat system built at Gavra Games and shipped inside Warriors: Rise to Glory. Each die resolves to damage, shield, self-damage or return, and the system handles turn order, effect resolution and win conditions over a shared state machine.
